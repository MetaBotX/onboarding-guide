# Getting Started at MetaBotX

Welcome to MetaBotX! This guide will help you get started as a new engineer. Follow these steps to set up your development environment and begin contributing to MetaBotX projects.

## Your First Day

### 1. Access and Accounts

- [ ] Receive repository access from your team lead
- [ ] Set up GitHub account (if not already done)
- [ ] Configure SSH keys for GitHub access
- [ ] Join MetaBotX communication channels (Slack, Teams, etc.)
- [ ] Get access to required tools and services

### 2. Initial Setup

- [ ] Clone the onboarding guide repository
- [ ] Review this getting started guide
- [ ] Complete the [Project Setup Checklist](project-setup.md)
- [ ] Set up your development environment

### 3. Learn the Basics

- [ ] Read [Gitflow Branching Strategy](../git-workflow/gitflow-strategy.md)

## Essential First Steps

### Repository Access

1. **Get Repository Access**
   - Your team lead will grant you access to MetaBotX repositories
   - You'll receive an invitation via GitHub
   - Accept the invitation to gain access

2. **Clone Repository**
   ```bash
   git clone git@github.com:metabotx/repository-name.git
   cd repository-name
   ```

3. **Verify Access**
   - Try cloning a repository
   - Verify you can push to a test branch
   - Confirm you can create pull requests

### Development Environment

Follow the [Project Setup Checklist](project-setup.md) to:
- Install required tools and dependencies
- Configure your development environment
- Set up project-specific configurations
- Verify everything works correctly

### Understanding MetaBotX Workflows

1. **Git Workflow**
   - Learn how MetaBotX uses Gitflow
   - Understand branch naming conventions
   - Know when to create feature branches

2. **Pull Request Process**
   - Learn how to create effective PRs
   - Understand the review process
   - Know merge strategies

3. **Code Quality Standards**
   - Review code review guidelines
   - Understand best practices
   - Learn about tools and utilities

## Week 1 Goals

By the end of your first week, you should:

- [ ] Have your development environment fully set up
- [ ] Understand MetaBotX Git workflow
- [ ] Know how to create and merge pull requests
- [ ] Be familiar with code review process
- [ ] Have made your first contribution (even if small)
- [ ] Know where to find help and documentation
