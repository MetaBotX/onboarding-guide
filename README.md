# MetaBotX Engineering Onboarding Guide

Welcome to MetaBotX! This comprehensive onboarding guide provides everything you need to get started as a new engineer at MetaBotX.

## Documentation Site

This documentation is available as a website: **[View Documentation Site](https://metabotx.github.io/onboarding-guide/)**

The site is automatically updated when changes are pushed to the `main` branch.

## Local Development

To preview the documentation locally:

```bash
# Install dependencies
pip install -r requirements.txt

# Serve documentation locally
mkdocs serve

# Build documentation
mkdocs build
```

## Structure

- `docs/` - Documentation source files
  - `onboarding/` - Getting started guides
  - `git-workflow/` - Git and version control guides
  - `engineering-practices/` - Code quality and best practices
  - `examples/` - Practical examples
- `mkdocs.yml` - MkDocs configuration
- `.github/workflows/pages.yml` - GitHub Pages deployment

## Contributing

To contribute to this guide:

1. Create a feature branch following Gitflow
2. Make your changes
3. Submit a pull request
4. Get review and approval
5. Merge using squash merge

See the documentation for details on our Git workflow and contribution process.
